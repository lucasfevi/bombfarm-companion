The hero leaderboard's Abilities column now shows each hero's ability icons instead of a count — hover one for its name and level — and still sorts by how many abilities a hero has, then by their levels. The Columns control became a searchable checklist like the Inventory's set filter: type to find a column, tick to show it, untick to hide it. The "click a column to sort" hint moved into an info icon beside the roster title.
