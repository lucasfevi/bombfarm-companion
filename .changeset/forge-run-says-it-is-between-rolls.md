A forge run now tells you when it is between rolls.

A run leaves a gap between one roll and the next. Most are a second or two and pass for the roll
itself, but every so often one runs to several seconds, and the screen went completely quiet for
it: no new mark on the chart, no figure moving, nothing to say the run was still yours. Watching a
real climb, that reads as frozen.

The running header now says `pausing…` beside the roll count for the length of a gap long enough
to notice, with the dots animating gently — still, like everything else on this screen, for anyone
who has asked for less motion. It goes as soon as the next roll lands.

It is only ever shown for the long gaps. A word blinking on and off every single roll would be
worse than the quiet it replaced, so a gap under a second and a half passes in silence.
