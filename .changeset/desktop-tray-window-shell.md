On Windows, closing the companion window now hides it to the system tray instead of quitting. Live
tracking keeps running while the window is hidden. Right-click the tray icon for **Show** and
**Quit**; left-click or double-click the icon also brings the window back.

The main window can be pinned always-on-top from Settings, and it remembers where you left it —
size, position, and maximized state — across restarts on the same display.
