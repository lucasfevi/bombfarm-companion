The desktop Gear tab can now compare gear: copy your current gear into an editable clone, change item level, rarity and forge on it, and see the whole hero sheet laid against the current one, with the clone's value under each stat that changes and a Δ clone column for the difference. The table keeps only the columns gear can change (gear, points, skill tree, runes, total), an info icon beside the title explains it and points to the Points tab for the full breakdown, and the Over cap column measures crit chance against 80%, assuming Deadly Omen's +20% crit chance is on the team. Your current gear stays read-only because it comes from the running game.
